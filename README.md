# NEXORA — Fashion E-Commerce Demo

A responsive front-end e-commerce portfolio project built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository (for example `nexora-store`).
2. Upload `index.html`, `style.css`, and `app.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

## Demo features
- Product catalogue with category filters, search and sorting
- Product detail view and size selection
- Shopping cart with quantity controls
- Wishlist
- Demo account sign-in
- Checkout form and local demo order creation
- Admin dashboard: product add/delete, order list/status, export demo data
- Responsive mobile layout

## Admin demo access
- Open **Admin access** in the footer.
- Demo code: `NEXORA2026`

## Important limitations
This is a portfolio/demo storefront. Cart, account, products and orders are stored in the visitor's browser using LocalStorage. Admin access is not secure. There is no database, server-side authentication, real payment gateway, inventory synchronization, or real order processing. Do not use real customer information or collect actual payments with this demo.

Business details and contact information shown on the website are fictional placeholders. Replace them before presenting a real business.
Product photos are loaded from Unsplash and require an internet connection.
